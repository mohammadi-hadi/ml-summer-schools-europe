# Contributing

Additions and corrections are welcome.

## Adding a school

- One school per pull request.
- European (or online-with-strong-European-participation) ML/AI schools only; for a global list see awesome-mlss.
- Provide: name, host/location pattern, focus, the usual month **only if it has been stable across recent editions**, and a link that loads.
- Prefer the school's long-lived site over a year-specific page; if only year pages exist, link the most recent one.

## Corrections

Dates and venues drift. If a link is dead or a "usually" is no longer true, open an issue or a PR — the link checker runs weekly, but human eyes catch more.

## Style

Keep descriptions short and factual. No rankings — schools differ by focus, not by rank.
